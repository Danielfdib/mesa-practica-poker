# Mesa de Práctica NL2

Mesa de poker 6-max (cash NL2, 100bb) para practicar contra 5 rivales bot: dos pagadores, un nit, un regular y un maníaco. Tu posición rota cada mano. Al final de la sesión ves el resultado, el resultado respetando los rangos de apertura, VPIP/PFR, resultado por posición y las decisiones preflop fuera del plan.

Es una sola página estática (`index.html`), sin dependencias. Se publica en Vercel como sitio estático, sin build.

`index.html` se genera con `build.ps1` a partir de la fuente del curso (`../practica/mesa-practica.html`). No editar `index.html` a mano.
